## Como concluir a publicação

1. Restabelecer o ambiente reconectando a conexão GitHub usada por ele em **Settings > Plugins** e iniciar uma nova tarefa cloud, conforme o diagnóstico `github_reauthentication_required`.
2. Usar `repositories.json` como manifesto para criar os cinco repositórios públicos, com nome, descrição e tópicos indicados.
3. Copiar os três READMEs de cada pasta para a raiz do respectivo repositório.
4. Usar os arquivos originais já enviados no chat nos destinos indicados. Os comentários `PORTFOLIO_IMAGE` marcam os locais de inserção das imagens: substituir cada comentário por Markdown com o caminho local e a legenda do idioma, somente após o arquivo existir.
5. Conferir as imagens renderizadas, os links entre os três idiomas e os botões de WhatsApp. Só então adicionar os novos destinos ao perfil.

## Critérios editoriais

Cada repositório tem uma finalidade própria. A documentação usa português, espanhol e inglês naturais; não repete listas extensas de palavras-chave. Características visíveis são descritas como interface. Integrações e funções não comprovadas são tratadas como escopo a definir. Não há stack, resultados, preços, prazos ou compatibilidades inventados.

Não são necessários novos exemplos nem acesso ao código-fonte para concluir esta apresentação com as imagens já fornecidas.
